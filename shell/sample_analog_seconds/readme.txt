# ゴースト「うかくろっく」への追加シェル作成時のファイル流用について
sample_analog_secondsフォルダの中身は、
readme.txtとprofileフォルダ以下を除き、すべて流用可能です。
必要に応じて内容を変更してください。

作成した追加シェルを配布する前に、
作者名・シェル名・シェルフォルダ名を【必ず】変更してください。
(descript.txtおよびinstall.txtに項目があります)

また、psdフォルダ以下は作業用の素材ファイルです。
追加シェル配布時はpsdフォルダごと削除してください。


# 判定方式
シェル名またはシェルフォルダ名に「analog」が含まれていれば、
ゴーストはシェルをアナログとみなします。
（両方を満たしても対応とみなされます）

## 秒表示について
秒表示対応と共存できます。
秒針なしのアナログ時計も作れます。

## 秒表示しない場合
このテンプレートへ以下の対応を行ってください。
* surface300.png～surface359.png : 削除
* surfaces2.txt : 削除


# アナログ対応に必須の内容
## 必須サーフェスID
*  0 : 時計本体
* 10 : \1のデフォルトサーフェスとして必要

## 必須アニメーションID
### 秒表示対応をしない場合
*   0 ～  59 : 時 / 300000ミリ秒ごとに1目盛り増
* 200 ～ 259 : 分 /  60000ミリ秒ごとに1目盛り増

### 秒表示対応をする場合
*   0 ～  59 : 時 / 300000ミリ秒ごとに1目盛り増
* 200 ～ 259 : 分 /  60000ミリ秒ごとに1目盛り増
* 400 ～ 459 : 秒 /   1000ミリ秒ごとに1目盛り増


# 廃止した仕様
2023年6月18日に、以下のアニメーションIDを不使用（欠番）にしました。
ゴーストがこれらのIDのアニメーションを直に指定することはなくなったので、他の何かに割り当てることも可能です。
## タイマー系（減っていく）
* 100 ～ 159 : 時 / 300000ミリ秒ごとに1目盛り減
* 300 ～ 359 : 分 /  60000ミリ秒ごとに1目盛り減
* 500 ～ 559 : 秒 /   1000ミリ秒ごとに1目盛り減
